**Goal:** Implement v1.1 per spec `docs/superpowers/specs/2026-08-19-v1.1-security-and-utilities-design.md`: RBAC (roles + per-table grants), composite keys, ID masking, SQLi hardening, slog request logging.

### Task 1: `internal/tokenid` — Feistel ID codec

**Files:**
- Create: `internal/tokenid/tokenid.go`
- Test: `internal/tokenid/tokenid_test.go`
- Modify: `internal/meta/meta.go` (add `IDSecret()` mirroring `SessionSecret()` with key `id_secret`)

**Interfaces (produces):**
```go
func New(secret []byte) *Codec
func (c *Codec) Encode(kind string, id int64) string
func (c *Codec) Decode(kind, token string) (int64, error)
```

Algorithm: 4-round Feistel over uint64; round fn `F(kind, i, r) = first 4 bytes of HMAC-SHA256(secret, kind|0x1f|i(byte)|bigendian(r))`. Forward `(l,r) → (r, l^F_i(r))`; inverse `(l,r) → (r^F_i(l), l)` descending i. Token = `base64.RawURLEncoding` of 8-byte big-endian permuted value (11 chars, no padding).

Tests: roundtrip many ids across all kinds; deterministic; 11 chars & url-charset; `Decode` rejects bad length/charset; domain separation (`Decode("td", Encode("ds",5)) != 5`); distinctness for ids 0..5000; `IDSecret` persists.

Migration 3 SQL (single tx, runs for fresh AND v1.0 DBs):
```sql
CREATE TABLE roles(id INTEGER PRIMARY KEY AUTOINCREMENT, name TEXT NOT NULL UNIQUE,
  is_admin INTEGER NOT NULL DEFAULT 0, platform_manage INTEGER NOT NULL DEFAULT 0,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP);
INSERT INTO roles(id,name,is_admin,platform_manage) VALUES(1,'Admin',1,1);
ALTER TABLE users ADD COLUMN role_id INTEGER NOT NULL DEFAULT 1;
ALTER TABLE users ADD COLUMN disabled INTEGER NOT NULL DEFAULT 0;
ALTER TABLE users ADD COLUMN is_first INTEGER NOT NULL DEFAULT 0;
UPDATE users SET is_first=1 WHERE id=(SELECT MIN(id) FROM users);
CREATE TABLE role_table_grants(role_id INTEGER NOT NULL REFERENCES roles(id) ON DELETE CASCADE,
  table_def_id INTEGER NOT NULL REFERENCES table_defs(id) ON DELETE CASCADE,
  can_read INTEGER NOT NULL DEFAULT 0, can_create INTEGER NOT NULL DEFAULT 0,
  can_update INTEGER NOT NULL DEFAULT 0, can_delete INTEGER NOT NULL DEFAULT 0,
  PRIMARY KEY(role_id,table_def_id));
ALTER TABLE table_defs ADD COLUMN key_columns TEXT NOT NULL DEFAULT '[]';
UPDATE table_defs SET key_columns=json_array(pk_column);
ALTER TABLE table_defs DROP COLUMN pk_column;
```
Upgrade test builds a v1.0-shaped DB by running `migrations[:2]` on a raw sqlite DB + inserting user/def, then `meta.Open` and asserts migration 3 effects.

**Interfaces (produces):**
```go
// users.go
type User struct { ID int64; Username string; RoleID int64; Disabled, IsFirst bool }
func (s *Store) CreateUserWithRole(username, password string, roleID int64) error

type Role struct { ID int64; Name string; IsAdmin, PlatformManage bool }

func (s *Store) ListRoles() ([]RoleWithGrants, error) // + Grants []TableGrant + UserCount int
```

`User` context type carries `RoleID, IsAdmin, PlatformManage` (rename: `GetUserContext` returns a `UserCtx` struct). `CreateFirstUser`/`CreateUser` set role Admin; first user sets `is_first=1` (only when inserted row is MIN(id)).

### Task 4: `internal/api` — tokenid plumbing + auth/RBAC + CtxUser

**Files:**
- Modify: `internal/api/server.go` (Server.ids field, writeErr ctx stash, routes+gates, permissions DTO), `auth.go` (RequireAuth→UserCtx, RequirePlatform, RequireAdmin, handleMe), `datasources.go`, `tables.go`, `audit.go` (token decode/encode, username join), `setup.go` (unchanged semantics), `rows.go` (perm gates + composite keys), `rows` tests, new `internal/api/rbac_test.go`, `internal/api/rowkey.go` (`encodeRowKey([]string) string`, `decodeRowKey(string) ([]string, error)`)

**Key mechanics:**
- `Server` gains `ids *tokenid.Codec`; `New(store)` builds it from `store.IDSecret()`.
- `writeErr` stashes `{code,msg}` into context value for the logging middleware.
- `tableCtx(r)`: decode `td` token; `dsCtx(r)`: decode `ds` token.
- Row endpoints check `perm(u, defID, perm)` — admin bypass; else `GrantsFor(u.RoleID, defID)`.
- `GET /api/tables` filtered for non-platform users (can_read only); `GET /api/tables/{id}` allowed platform-or-can_read, response embeds `permissions`.
- `GET /api/auth/me` → `{username, isAdmin, platformManage}`.
- Row key codec: `encodeRowKey(["3"]) == "WyIzIl0"`; decode validates JSON array of strings, no nulls.
- Audit list: decode `tableDefId`/`userId` tokens; entries out: masked ids + `username` (JOIN users).
- meta.AuditEntry gains `Username string \`json:"username"\`` filled by ListAudit LEFT JOIN.
