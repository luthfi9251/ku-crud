> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver v1.3 — CSV import/export, bulk delete, many-to-many junction relations, UUID/JSON column types, datasource password encryption, login rate limiting, default sort.

**Architecture:** Stdlib-Go HTTP + SQLite metadata + adapter layer (PG/MySQL), React 19 SPA. All new features follow existing patterns: `writeErr` envelope, masked ids, per-table RBAC gates, adapter interface, parameterized SQL via sqlkit builders, per-column storage in `columns` table.

**Tech Stack:** Go 1.25 (stdlib only — no new Go deps), React 19 + Vite + TS strict + TanStack Query + shadcn/ui (vendored), `encoding/csv`, `crypto/aes`+`crypto/cipher` (GCM).
